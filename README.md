# DaData Reverse Geocoding

Тестовое задание для позиции Junior Python Developer.

Веб-приложение принимает координаты, отправляет запрос к API DaData, получает полный адрес и отображает результат на отдельной HTML-странице в виде карточки.

Полное условие задания находится в файле [`Task.md`](Task.md).

## Возможности

* ввод широты и долготы через HTML-форму
* получение адреса по координатам с помощью API DaData
* разделение полного адреса на отдельные составляющие
* отображение результата на отдельной HTML-странице
* обработка ошибок соединения и HTTP-ошибок

## Стек

* Python 3.7
* Bottle
* DaData API
* HTTPX
* HTML

## Запуск проекта

Проект разрабатывался и запускался в Ubuntu 18.04.6 LTS.

### 1. Клонирование репозитория

Откройте терминал и выполните команду:

```bash
git clone https://github.com/katrinvarf/dadata-reverse-geocoding.git
```

Перейдите в каталог проекта:

```bash
cd dadata-reverse-geocoding
```

### 2. Создание виртуального окружения

```bash
python3.7 -m venv venv
```

### 3. Активация виртуального окружения

```bash
source venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Запуск приложения

Для работы приложения необходим токен API DaData.

Запустите приложение, указав токен в аргументе командной строки:

```bash
python3.7 application.py --token "ваш_токен"
```

### 6. Открытие приложения

После запуска откройте в браузере страницу:

```text
http://localhost:8080/test_task/
```
